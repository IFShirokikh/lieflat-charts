# Обновление локальных зависимостей

Обновляй вендорные файлы отдельным изменением.

1. Скачай пакет из официального npm-реестра или исходного репозитория.
2. Проверь версию, лицензию и происхождение.
3. Замени только нужные minified JS, WOFF2 или GeoJSON.
4. Пересчитай SHA-256 и обнови `vendor/manifest.json`.
5. Запусти `npm test` и `npm run test:browser` без доступа к сети.
6. Просмотри diff манифеста и лицензий вручную.

Автоматическое слияние обновлений upstream запрещено: старые HTML-шаблоны могут вернуть CDN, сетевые загрузки или опасные DOM-sinks.
