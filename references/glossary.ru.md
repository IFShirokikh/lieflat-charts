# Глоссарий

| Термин | Использовать | Не использовать |
|---|---|---|
| chart | график / диаграмма по контексту | чарт |
| dashboard | панель показателей | дашборд в пользовательских подписях |
| source | источник | source |
| no data | нет данных | N/A |
| value | значение | value |
| category | категория | category |
| report | отчёт | репорт |
| range | диапазон | range |
| network | сеть связей | граф без пояснения |

Технические ID, имена API, названия библиотек и пользовательские данные не переводятся.
