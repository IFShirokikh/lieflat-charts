# Каталог Lieflat Charts

Единственный машинный источник истины — `templates/catalog.ru.json`. Все 64 технических ID графиков сохранены. Входные контракты описаны в `references/spec-v1.md`.

## Как выбирать

1. Для обычной визуализации сначала сравни `L1`–`L20` и `F1`–`F17`.
2. `G1`–`G22` используй для дашбордов, мониторинга и быстрого чтения.
3. `M1`–`M2` выбирай только при явном запросе на карту.
4. `B1`–`B3` предназначены для крупных интерактивных сетей и потоков.
5. Один график должен отвечать на один самостоятельный вопрос.

## Glance, карты и большие графики

- `G1`–`G22`: быстрые варианты линий, столбцов, долей, матриц, сетей, распределений и потоков.
- `M1`: карта штатов США; `M2`: карта мира. GeoJSON встроен в готовый файл.
- `B1`: круговая сеть; `B2`: силовая сеть; `B3`: потоковая диаграмма.

Названия и тип движка для каждого ID смотри в `templates/catalog.ru.json`. Все варианты используют единый локальный ECharts 6.1.0 и SVG-рендерер; Chart.js отсутствует.
