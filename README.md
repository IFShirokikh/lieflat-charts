# Lieflat Charts — безопасные офлайн-графики

Русскоязычный скилл и локальный компилятор для создания самодостаточных HTML-графиков и отчётов. Готовый файл открывается через `file://`, не требует сервера или интернета и не содержит сетевых каналов.

## Быстрый старт

Требуется Node.js 20 или новее. Установка npm-пакетов не нужна: ECharts, шрифты и карты уже зафиксированы в `vendor/`.

```bash
node scripts/build-offline.mjs --spec examples/specs/bar.ru.json --out output/chart.html
node scripts/validate-output.mjs output/chart.html
```

На вход компилятор принимает только JSON по схеме `schemas/spec-v1.schema.json`. Пользовательские строки считаются недоверенными: HTML, URL, обработчики событий и JavaScript в них запрещены. Результат содержит данные в Base64 внутри неисполняемого блока, локальные шрифты, ECharts и строгую CSP. Проверка результата заново собирает канонический документ из встроенной спецификации и принимает HTML только при полном побайтовом совпадении.

## Поддержка шаблонов

- Lupi Editorial: `L1`–`L20`.
- Basics: `F1`–`F17`.
- Glance: `G1`–`G22`.
- Карты: `M1`–`M2`.
- Интерактивные большие графики: `B1`–`B3`.
- Полностраничные отчёты: `R01`–`R12`.

Технические ID сохранены, но старые исполняемые HTML-шаблоны удалены. Их заменяет декларативный каталог `templates/catalog.ru.json`, а единственный доверенный рендерер находится в `scripts/runtime.js`.

## Гарантии и границы

Компилятор и проверка результата гарантируют отсутствие сетевых запросов, внешних ресурсов и опасных DOM-вставок в создаваемом HTML. Репозиторий не может гарантировать безопасность агента, браузерных расширений, операционной системы или ручной передачи файлов. Подробности: `references/threat-model.md`.

## Проверки

```bash
npm test
npm run test:browser
```

Первый набор проверяет все ID шаблонов, XSS, CSP, контрольные суммы, локализацию и детерминированность. Второй открывает все результаты через `file://` в установленном Chromium/Chrome и проверяет ошибки страницы и сетевые события.
